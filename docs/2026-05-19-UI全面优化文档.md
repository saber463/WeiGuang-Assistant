# 微光畅行 Weiguang Plus — UI 全面优化文档

## 一、优化目标

- 提升整体视觉层次感与美观度
- 增强操作流畅度（动画过渡）
- 改善无障碍体验（大触控目标、高对比度）
- 统一所有页面的卡片风格（Material3 设计语言）
- 适配各类屏幕尺寸（响应式间距优化）

## 二、总体优化项目

### 2.1 页面切换动画

| 文件 | 修改内容 |
|------|----------|
| MainActivity.kt | 使用 `AnimatedContent` 替代直接 `when` 切换，添加 `fadeIn + fadeOut + SizeTransform` 动画过渡效果 |

```kotlin
AnimatedContent(
    targetState = currentSection,
    transitionSpec = {
        fadeIn(animationSpec = spring(dampingRatio = 0.9f)) togetherWith
            fadeOut(animationSpec = spring(dampingRatio = 0.9f)) using
            SizeTransform(clip = false)
    },
    label = "ScreenTransition"
) { section -> ... }
```

### 2.2 导航栏优化 (NavigationBar)

| 文件 | 修改内容 |
|------|----------|
| MainActivity.kt | 添加 `tonalElevation`、`containerColor`；自定义选中/未选中图标和文字的 colors |

- 选中图标/文字色：`primary`
- 选中指示器：`primaryContainer`
- 未选中色：`onSurfaceVariant`
- 背景：`surface`

### 2.3 卡片系统优化 (Card)

所有卡片统一样式规范：

| 卡片类型 | 背景色 | elevation | 圆角 |
|----------|--------|-----------|------|
| HeroCard | primaryContainer | 4.dp | 24.dp |
| FeatureCard | 默认(surface) | 2.dp | 20.dp |
| HighlightCard | secondaryContainer | 3.dp | 20.dp |
| WarningCard | errorContainer | 3.dp | 20.dp |
| InfoCard | 默认(surface) | 1.dp | 20.dp |

### 2.4 滚动页面间距优化 (ScrollPage)

| 文件 | 水平内边距 | 卡片间距 |
|------|-----------|---------|
| MainActivity.kt | 20.dp | 12.dp |
| VisionScreen.kt | 20.dp | 16.dp |

## 三、各页面详细优化

### 3.1 MainActivity.kt (主界面)

- **新增导入**: `AnimatedContent`, `SizeTransform`, `spring`, `slideInHorizontally`, `slideOutHorizontally`, `togetherWith`, `NavigationBarItemDefaults`
- **WeiguangPlusApp Composable**:
  - TopAppBar 副标题显示优化（首页显示"v2.0 · 全面无障碍助手"）
  - NavigationBar 添加 Material3 规范的 colors 配置
  - 页面切换使用 `AnimatedContent` 过渡动画
- **HeroCard**: 添加 elevation 4.dp，标题文字使用 `onPrimaryContainer` 颜色
- **FeatureCard**: 添加 elevation 2.dp，标题和状态 chip 同行显示，底部添加 ✦ 装饰符号
- **HighlightCard/WarningCard**: 添加 elevation 3.dp
- **InfoCard**: 添加 elevation 1.dp
- **SectionTitle**: 间距微调（top: 8dp → bottom: 2dp）
- **StatusChip**: 精简 padding，添加 primary 色圆点装饰
- **InfoLine**: 标签加粗、间距优化
- **TimelineLine**: 添加垂直 padding，Alignment.Top 对齐

### 3.2 VisionScreen.kt (视觉识别页面)

- **HeroCard**: 添加 elevation 2.dp，标题使用 `onPrimaryContainer` 颜色
- **HighlightCard/InfoCard/ObstacleCard/相机预览 Card**: 统一添加 elevation 2.dp
- **TabRow**: 保留 `surface` 容器色，移除不兼容的 selectedContentColor/unselectedContentColor
- **Tab 选中态**: 使用 `primary` 背景 + 顶部圆角（topStart=12.dp, topEnd=12.dp）
- **TabRow contentColor**: 设置为 `onSurface`
- **ScrollPage**: 内边距从 16dp 增加到 20dp，卡片间距从 12dp 增加到 16dp

### 3.3 TTSSettingsScreen.kt (语音设置页面)

- **新增导入**: `ButtonDefaults`, `SliderDefaults`
- **HeroCard**: 添加 elevation 4.dp，标题使用 `onPrimaryContainer` 颜色
- **InfoCard**: 添加 elevation 1.dp
- **HighlightCard**: 添加 elevation 2.dp
- **Slider**: 设置 `colors = SliderDefaults.colors(thumbColor=primary, activeTrackColor=primary)`
- **PlayButton**: 设置 `colors = ButtonDefaults.buttonColors(containerColor=primary)`
- **ScrollPage**: 卡片间距从 12dp 增加到 20dp

### 3.4 VoiceAssistantScreen.kt (语音助手页面)

- **HeroCard**: 添加 elevation 4.dp，标题使用 `onPrimaryContainer` 颜色
- **HighlightCard**: 添加 elevation 2.dp
- **InfoCard**: 添加 elevation 1.dp
- **AssistantCard**: 添加 elevation 2.dp
- **OneClickWakeCard (唤醒按钮)**: 高度从 56dp 增加到 60dp，圆角从 16dp 增加到 24dp，添加 `primaryContainer`/`onPrimaryContainer` 配色
- **ScrollPage**: 卡片间距从 12dp 增加到 16dp

## 四、颜色系统 (Color.kt)

Material3 完整色板已定义：

- **Primary**: #6750A4 (紫色主色)
- **Secondary**: #625B71
- **Tertiary**: #7D5260
- **Error**: #B3261E
- **Dark 模式** 对应的深色色板同样完整定义
- 支持 Android 12+ 动态取色 (`dynamicLightColorScheme`/`dynamicDarkColorScheme`)

## 五、主题系统 (Theme.kt)

- 支持 Android 12+ 动态颜色 (Dynamic Color)
- 自动根据系统设置切换 Light/Dark 模式
- 自定义 Typography (`AppTypography`)

## 六、无障碍适配优化

- 所有图标按钮都设置了 `contentDescription`
- Card 组件使用 Material3 默认无障碍支持
- NavigationBarItem 自动适配 TalkBack
- 按钮内边距符合 48dp 最小触控目标规范
- 颜色对比度满足 WCAG 标准（使用 Material3 预设色板）

## 七、稳定性和性能优化

- 使用 `remember` 缓存预览视图和识别器实例
- TTSManager 全局单例管理，避免重复创建
- ImageAnalysis 使用 `STRATEGY_KEEP_ONLY_LATEST` 减少帧处理压力
- Room 数据库同步操作放在 IO 协程中
- 相机生命周期绑定到 Activity 生命周期，自动释放资源
- AnimatedContent 使用 `spring` 动画（弹性小、阻尼大），避免过度动画消耗
