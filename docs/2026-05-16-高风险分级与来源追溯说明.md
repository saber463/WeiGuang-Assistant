# 2026-05-16 高风险分级与来源追溯说明

## 1. 文档目标

这份文档用于说明微光畅行药品模块本轮新增的两项关键能力：

1. 高风险分级展示
2. 数据来源与授权追溯

目标是让产品页面、数据结构、离线库、答辩口径保持一致，避免出现“页面有提醒但数据不可追溯”或“数据有来源但用户看不到风险等级”的断层。

## 2. 本轮新增内容

### 2.1 高风险分级

当前药品规则按以下等级处理：

- `high`
- `medium`
- `low`

在本地数据库查询后，Repository 会从药品命中的全部规则中提取最高风险等级，并透出给 UI 层。

### 2.2 数据来源追溯

本轮在药品主表中新增两个字段：

- `source_tag`
- `license_note`

作用：

- `source_tag`：记录数据来源类别，例如 `seed_demo`、`nmpa_sync`、`datasn_licensed`
- `license_note`：记录授权或使用备注，明确是否仅限比赛演示、是否已授权、是否需进一步核验

## 3. 代码落点

### 3.1 数据实体

`DrugMasterEntity` 新增：

- `sourceTag`
- `licenseNote`

### 3.2 聚合模型

`DrugInfo` 新增：

- `highestRiskLevel`
- `sourceTag`
- `licenseNote`

### 3.3 Repository 逻辑

`LocalDrugRepository` 负责：

1. 查询药品规则
2. 计算最高风险等级
3. 将来源标签和授权备注聚合到页面模型

### 3.4 UI 展示

药品页新增：

- 风险分级卡片
- 数据来源字段
- 授权备注字段

## 4. 当前高风险展示逻辑

### 4.1 展示规则

#### 高风险

显示文案：

- 高风险人工复核
- 请立即停止自行判断，优先咨询医生、药师或监护人

#### 中风险

显示文案：

- 中风险重点复核
- 请结合说明书、既往病史和当前用药做重点核对

#### 低风险

显示文案：

- 低风险继续核对
- 请继续核对说明书和用户个人情况后再决定下一步

#### 未分级

显示文案：

- 一般安全提醒
- 当前仅能提供辅助信息，请继续人工复核

### 4.2 当前样式

当前使用高对比度警示卡片承载风险结果，优先突出：

- 风险级别
- 下一步动作
- 来源标签
- 授权备注

## 5. 当前来源追溯策略

### 5.1 比赛演示样本

当前示例数据统一使用：

- `source_tag = seed_demo`
- `license_note = 仅限比赛演示样本，不作为正式商用药品数据库授权证明`

### 5.2 后续建议的来源值

建议后续统一使用以下来源标签：

- `seed_demo`
- `nmpa_sync`
- `manual_curated`
- `datasn_licensed`
- `hospital_coop`

### 5.3 后续建议的授权备注

建议授权备注按真实状态记录，例如：

- 仅限比赛演示样本
- 已完成购买授权，可用于正式发布版本
- 来源待复核，暂不可商用
- 仅作结构参考，不可二次分发

## 6. 对用户安全的意义

这一轮调整的核心价值有两层：

### 6.1 对用户

用户看到的不再只是药名和说明书，而是：

- 当前风险级别
- 是否需要立即人工复核
- 当前数据来自哪里

### 6.2 对团队

团队后续做数据扩容、接第三方数据库、准备答辩时，都可以准确区分：

- 哪些数据只是演示样本
- 哪些数据已具备授权
- 哪些数据暂时只能参考不能发布
