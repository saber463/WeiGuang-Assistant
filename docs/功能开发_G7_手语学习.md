## 一、背景与目标

将微光守护从「手语识别工具」扩展为「手语学习平台」，面向听障用户及手语学习者提供三大能力：

1. **手语词典查询**：输入文字查询对应手势动作，展示动作要点与标准手型示意；
2. **学习教程**：按难度分级的课程（基础日常 → 进阶礼貌 → 场景表达），每课含动作详解与跟练指引；
3. **练习纠错**：用户对前置摄像头做手势，系统实时给出正确度评分与逐项纠正建议（如"食指弯曲状态不对，应伸直展开"）。

## 二、技术方案

### 2.1 数据模型

- `SignCourseItem`：手语词条，含 `chinese`（中文词义）、`textTranslation`（识别语句）、`scene`（场景分类）、`difficulty`（难度 1~3）、`tips`（动作要点）、`target`（标准手指目标状态）。
- `GestureTarget`：标准手势目标，描述每根手指的期望状态（`FingerExpectation`：BENT 弯 / STRAIGHT 伸 / ANY 自由）及「拇指-食指接触」标志。
- 均为纯 Kotlin 数据类，不依赖 Room —— 本次使用内置静态词库（`SignCourseCatalog`），未引入数据库迁移成本；后续如需扩展海量词条可平滑迁移到 Room。

### 2.2 词条数据源

- `SignCourseCatalog`（object 单例）：内置 9 个词条，覆盖求助/日常/情感/问候/进阶表达场景，按难度 1~3 分级。
- 每个词条的 `GestureTarget` 与 `GestureClassifier` 的几何分类规则**保持一致口径**，确保"识别"与"纠错"对同一手势判读一致，避免前后矛盾。
- 提供 `search`（词典关键字匹配）、`groupedByScene` / `groupedByDifficulty`（课程分组）、`findById` 访问接口。

### 2.3 纠错算法

`SignLanguageCorrector`（纯函数，可独立测试）：
- 逐根手指计算"是否弯曲"：指尖到手腕距离 < 根部(MCP)到手腕距离 × 0.85 ⇔ 弯曲（与 `GestureClassifier.isFingerBent` 判据一致）。
- 对约束为 BENT/STRAIGHT 的手指逐一比对他们期望状态；
- 对期望"拇指-食指接触"的手势（如 OK、比心）附加指尖距离阈值（归一化 < 0.06）判定；
- 汇总通过项占比 → **0~100 正确度评分**；将未通过项转为逐条纠正建议。

> **纠错参照说明**：由于工程内暂无标准姿势的原始 landmark 样本，纠错以"标准手指目标状态 + 几何规则"为参照，而非与预存 landmark 直接求距离。该方案无需额外标注数据即可运行，且可解释性强；后续若引入标准关键点数据集，可再升级为逐点距离/角度对比，无需改动 UI。

### 2.4 界面

`SignLearningScreen`（三 Tab）：
| Tab | 实现 |
|-----|------|
| 词典查询 | 输入框 + `SignCourseCatalog.search` 实时过滤，卡片展示词义/场景/难度/动作示意/要点 |
| 学习课程 | `CourseList`（按难度分组，课程清单）→ 点击进入 `CourseDetail`（动作要点 + 标准手型） |
| 练习纠错 | 词条选择 + `SignLanguageCameraManager`（前置摄像头预览）+ 实时 `SignLanguageCorrector` 评分建议 |

- 相机复用现有 `SignLanguageCameraManager` 的 `recognitionResult`（含 21 关键点）作为纠错输入；
- 摄像头仅在"练习 Tab"且用户点击"开始练习"后才启动，离开 Tab 时 `DisposableEffect` 释放相机，避免长期占用摄像头与线程资源。

## 五、实施记录

- **组装过程**：先以 `SignLanguageCameraManager.recognitionResult`（`SignLanguageResult.handLandmarks`，含主手 21 关键点）作为纠错输入，避免为练习功能单独重写相机管线。
- **纠错评分**：`correct(target, landmarks)` 对每根受约束手指执行弯曲比对，未知晓（ANY）的手指不计分不校验，避免过度约束导致合理手势被误判。
- **生命周期**：练习 Tab 独立 `remember` 相机管理器，`DisposableEffect.onDispose` 中 `release()`，规避摄像头资源泄漏。
- **关键点不完整保护**：`landmarks.size < 21` 时返回 `null`，UI 显示"等待手势稳定"，不做错误评分。

## 六、后续扩展（不在本次范围）

- 标准关键点数据集：引入后可将 `SignLanguageCorrector` 升级为逐点距离/关节角度对比，提升打分粒度。
- 跟练引导：在课程详情回放标准动作动画（如关键点轨迹动画），辅助跟练。
