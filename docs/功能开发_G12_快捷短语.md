## 一、背景与目标

预设常用短语库（如"请帮我叫医生""我要挂号"），供听障用户在聊天/通话辅助页一键选择，提升打字较慢用户的沟通效率。支持按场景分类、用户自定义添加。

## 二、技术方案

### 2.1 数据库
沿用项目"独立 Room 数据库"先例（如 ChatDatabase / TranscriptDatabase）：
- 新建 `QuickPhraseDatabase`（独立 .db），**不触碰主 AppDatabase**
- `QuickPhrase` 实体：id、分类 category、文本 text、是否自定义 isCustom、排序
- 首次启动用 `@Insert(onConflict=IGNORE)` 插入预设短语

### 2.2 核心交付
1. `QuickPhraseRepository`：统一短语数据源，提供预设短语 + 按分类查询 + 添加/删除自定义短语
2. `QuickPhraseManagerScreen`：管理页（查看短语库 / 添加自定义短语 / 删除）
3. `QuickPhraseBar` 组件：横向滚动短语栏，点击回调（供聊天/通话等页面复用）
4. 接入聊天页输入框上方；主页新增入口卡片

> 说明：CallAssistantScreen 已有自己的快捷短语列表（CallViewModel 内硬编码），本次不强行替换其数据源，避免大改通话页交互；统一短语库通过共享管理页沉淀，聊天页优先复用以验证扩展。

## 五、实施记录
- **ChatDetailScreen.kt**：在输入框区域上方增加 `LazyRow` 短语栏，通过 `QuickPhraseRepository.getAllPhrases()` 加载；点击短语：输入框为空则填入、非空则追加，均从 `QuickPhraseRepository` 走独立 `QuickPhraseDatabase`。
- **QuickPhraseRepository.kt**：`@Insert(onConflict=IGNORE)` 保证预设短语在火记录库为空时一次写入，不会与自定义短语冲突；`getAllPhrases()→ensurePresets()` 仅调用 `dao.getAll()`，无递归风险。
- **QuickPhraseManagerScreen.kt**：分组展示 + 新增自定义短语表单 + 滑动删除，`isCustom=true` 才允许删除。
