## 一、创新点概述

本次开发实现两个市场上**尚无竞品实现的**创新功能：

### 🔴 创新1：多模态感知融合引擎 (FusionPerceptionEngine)

**市场差距**：现有无障碍APP（Be My Eyes、Seeing AI等）都是单模块运作——视觉是视觉、听觉是听觉、震动是震动，互不关联。

**我们的突破**：首次将三大感知通道（视觉+听觉+触觉）打通到统一的事件总线，实现多模态融合响应。

**核心数据流**：
```
CameraX(物品识别/障碍物检测) ─┐
AudioCapture(声音检测) ───────┼──→ FusionPerceptionEngine ──→ TTS播报
Sensor(加速度/陀螺仪) ────────┘      (优先级排序+防抖去重)     震动编码
                                                                  UI状态更新
```

### 🔴 创新2：双屏实时手语对话系统 (DualSignScreen)

**市场差距**：现有手语翻译APP只做单向翻译（手语→文字 或 文字→手语），没有真正的双向实时对话会话模式。

**我们的突破**：同一屏幕内同时运行两条通道——
- 上半屏：前置摄像头捕捉手语 → AI识别 → TTS对健听人说话
- 下半屏：麦克风收音 → 语音识别 → 文字展示给听障人

**市场首创**：听障人和健听人面对面使用同一台手机即可完成完整对话。

## 三、修改文件清单

### MainActivity.kt
- 新增 `AppSection.DIALOGUE` 枚举值 + Person 图标
- 新增 `categoryToSections` 映射（听障/综合分类含对话页）
- `onCreate()` 初始化 `FusionPerceptionEngine.initialize(this)`
- 新增 `DualSignScreen(Modifier)` 路由

### ObstacleDetectionManager.kt
- 连接事件总线：障碍物检测结果 → `FusionPerceptionEngine.emitEvent()`
- 触发条件：每个有效障碍物（置信度达标）
- 事件映射：方向→左/前/右、距离→EMERGENCY(<2m)/HIGH(<5m)/MEDIUM
- 携带数据：direction、distance、isPerson、label

### CameraObjectRecognizer.kt
- 连接事件总线：物品识别结果 → `FusionPerceptionEngine.emitEvent()`
- 触发条件：置信度 > 0.6
- 特殊处理：person/dog/cat 设为 HIGH 优先级，其余 LOW

### SoundMonitoringService.kt
- 连接事件总线：声音检测结果 → `FusionPerceptionEngine.emitEvent()`
- 触发条件：确认人声 + 置信度 ≥ 0.6 + 防抖 3秒
- 映射：HUMAN_VOICE → VOICE_CALLING，其余 → ENVIRONMENT_SOUND
- 携带数据：soundType、eventName

## 五、触觉语言系统设计

震动编码器设计了20种独有的震动模式，每种事件类型有"震动指纹"：

| 事件类型 | 震动符号 | 节奏 | 含义 |
|----------|---------|------|------|
| OBSTACLE_AHEAD | `··-` | 100ms×3 | 短短短-前方障碍 |
| OBSTACLE_LEFT | `-··` | 100ms×3 | 长短短-左侧障碍 |
| OBSTACLE_RIGHT | `··-·` | 100ms×4 | 短长短短-右侧障碍 |
| CAR_HORN | `--` | 200ms×2 | 长长-汽车鸣笛 |
| DOORBELL | `···` | 80ms×3 | 短短短-门铃 |
| FIRE_ALARM | `----` | 400ms×4 | 长长长长-火灾警报 |
| BABY_CRYING | `·-·-` | 120ms×4 | 短长短长-婴儿哭声 |
| DEVICE_TILTED | `-·-·` | 200ms×4 | 长短长短-设备倾斜 |
| USER_HELP_REQUEST | `-·-·-` | 300ms×5 | 长短短长短-求助 |

## 七、使用指南

### 双屏手语对话
1. 打开APP → 选择"听障辅助"或"综合辅助"
2. 底部导航栏选择"对话"Tab
3. 上半屏：将手朝向手机前置摄像头
4. 下半屏：点击"开始说话"后对手机说话
5. 上下同步运行，实现实时对话

### 感知融合引擎（后台自动运行）
1. 无需用户手动操作
2. 当障碍物检测/声音检测/物品识别触发时，自动：
   - 高优先级事件（障碍<2m、火灾警报）→ TTS播报 + 震动提醒
   - 中优先级事件（普通障碍、人声）→ 震动提醒
   - 低优先级事件（物品识别）→ 仅入历史队列
