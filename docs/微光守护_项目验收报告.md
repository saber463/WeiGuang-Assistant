## 四、已知问题/缺陷清单

### 缺陷 #1：手语识别页崩溃（严重）

| 项目 | 内容 |
|------|------|
| 缺陷编号 | BUG-001 |
| 严重等级 | **High（严重）** |
| 问题现象 | 在首页点击"手语识别"卡片后，App 立即闪退崩溃 |
| 影响范围 | 手语识别模块完全不可用 |
| 根因分析 | MediaPipe 原生库 `libmediapipe_tasks_vision_jni.so` 未打包进 APK。`build.gradle.kts` 注释说明 AGP 8.2.0 存在 BUG（AAR 中的 .so 文件不会自动打包进 APK），需手动提取到 `src/main/jniLibs/{abi}/` 目录，但该 .so 文件缺失 |
| 复现步骤 | 1. 启动 App → 2. 在首页点击"手语识别"卡片 → 3. App 崩溃闪退 |
| logcat 摘要 | `FATAL EXCEPTION: main`<br>`Process: com.weiguangplus, PID: 4160`<br>`java.lang.UnsatisfiedLinkError: dlopen failed: library "libmediapipe_tasks_vision_jni.so" not found`<br>`at com.google.mediapipe.tasks.vision.core.BaseVisionTaskApi.<clinit>(BaseVisionTaskApi.java:37)`<br>`at com.weiguangplus.core.signlanguage.MediaPipeHandLandmarker.initialize(MediaPipeHandLandmarker.kt:44)`<br>`at com.weiguangplus.core.signlanguage.SignLanguageCameraManager.<init>(SignLanguageCameraManager.kt:58)`<br>`at com.weiguangplus.ui.screen.signlanguage.SignLanguageScreenKt.SignLanguageScreen(SignLanguageScreen.kt:94)` |
| 修复建议 | 从 MediaPipe tasks-vision AAR 中提取 `libmediapipe_tasks_vision_jni.so` 到 `app/src/main/jniLibs/{arm64-v8a,armeabi-v7a,x86_64}/` 目录后重新构建。或升级 AGP 版本修复 .so 自动打包问题 |

### 缺陷 #2：聊天页面无导航入口（一般）

| 项目 | 内容 |
|------|------|
| 缺陷编号 | BUG-002 |
| 严重等级 | **Medium（一般）** |
| 问题现象 | 聊天列表页（ChatListScreen）和聊天详情页（ChatDetailScreen）代码完整存在，但无法从首页导航到达 |
| 影响范围 | 聊天功能对用户不可见 |
| 根因分析 | `MainScreen` 的功能卡片列表中不包含聊天入口；`MainActivity` 导航路由 `"chat"` 和 `"chat_detail"` 虽已定义，但无 UI 触发点调用 `onNavigate("chat")` |
| 复现步骤 | 首页所有 6 个功能卡片中无"聊天"入口，用户无法进入聊天页面 |
| 修复建议 | 在 `MainScreen` 的 `features` 列表中添加聊天入口卡片（如 `FeatureCard("💬", "消息", "聊天消息", "chat")`） |

### 缺陷 #3：登录/注册页面无导航入口（一般）

| 项目 | 内容 |
|------|------|
| 缺陷编号 | BUG-003 |
| 严重等级 | **Medium（一般）** |
| 问题现象 | 登录页（LoginScreen）和注册页（RegisterScreen）代码完整存在，但无法从首页导航到达 |
| 影响范围 | 用户认证功能对用户不可见 |
| 根因分析 | `MainActivity` 导航 `when` 分支中不包含 `"login"` 和 `"register"` 路由配置；首页"设置"卡片路由到 `"settings"` 实际返回 `MainScreen`（同首页），未提供登录入口 |
| 复现步骤 | 首页点击"设置"卡片，返回的是首页而非设置/登录页面 |
| 修复建议 | 在 `MainActivity` 中添加 `"login"` 和 `"register"` 路由分支，并在首页或设置页中添加登录入口按钮 |

## 五、验收结论

### 5.1 总体结论

**附条件通过**

### 5.2 结论说明

微光守护 v1.3 在电脑模拟器（test_avd, Android 14）冒烟测试中：

- **7/10 项核心流程通过**（App 启动、首页渲染、用药识别、通话辅助、SOS、提醒设置、紧急联系人）
- **1 项核心流程崩溃**（手语识别页，因 MediaPipe 原生库缺失导致 `UnsatisfiedLinkError`）
- **2 项流程不可达**（聊天页和登录/注册页，因首页缺少导航入口）

App 的主体框架（首页导航、用药识别、通话辅助、SOS 紧急救助、提醒设置）功能正常，UI 渲染完整无崩溃。手语识别作为核心功能模块之一存在严重缺陷（原生库缺失），需修复后方可投入使用。聊天和认证模块代码完整但未接入导航入口，属于功能集成遗漏。

### 5.3 修复建议

1. **优先修复 BUG-001**：将 `libmediapipe_tasks_vision_jni.so` 手动提取到 `app/src/main/jniLibs/` 对应 ABI 目录，重新构建 APK 验证手语识别页不再崩溃。
2. **修复 BUG-002 和 BUG-003**：在首页添加聊天和登录/注册的导航入口按钮，完成功能集成。
3. 修复后需重新进行冒烟测试，确认所有核心流程通过后可升级为"通过"。
