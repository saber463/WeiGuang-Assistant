# 2026-05-16 首版 MVP 开发说明

## 本次迭代目标

基于“社会价值优先、4 天交付、公开数据驱动、面向听障用户与残联机构”的前提，对微光畅行项目完成首轮产品落地工作，重点是把 Android 空模板改造成可展示、可试用、可继续扩展的 MVP 演示应用。

## 本次迭代范围

### 已规划完成

- 输出首版产品与技术方案文档。
- 重构 App 首页信息架构。
- 新增三大模块入口：
  - 小玉手语沟通
  - 药品识别与风险提醒
  - 强提醒闹钟
- 补充无障碍导向文案和公益价值表达。

### 本次不做

- 摄像头实时识别接入。
- 真正 OCR 模型接入。
- 真正手语识别模型接入。
- 真正 TTS 流程接入。
- 鸿蒙原生适配。

## 代码设计原则

- 所有界面优先服务比赛展示与用户试用。
- 所有模块先做出完整故事闭环，再逐步替换为真实能力。
- 重要信息使用大字号、高对比度和卡片式布局。
- 所有医疗相关提示均保留辅助判断边界。

## 预期交付效果

- 用户首次打开应用即可理解项目价值。
- 演示时可以清楚展示三大模块的目标和当前进度。
- 真实用户试用时可以快速指出需求、反馈和下一步改进方向。

## 建议下一步开发项

1. 接入 CameraX 作为药品识别和手语识别视频采集入口。
2. 接入 OCR 引擎，先支持药盒名称识别。
3. 建立本地药品 JSON 数据表。
4. 建立用户健康档案表单页。
5. 打通 Android TTS 与振动模式配置。
