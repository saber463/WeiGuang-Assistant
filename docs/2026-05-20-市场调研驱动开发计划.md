## 六、技术方案建议

### 6.1 公交/地铁报站方案

```
方案A（离线版，推荐优先实现）：
  用户手动输入/选择公交线路
  → 基于GPS定位计算到站距离
  → 距离站点300m时触发预提醒震动
  → 距离站点100m时触发到站震动+大字弹窗
  → 支持自定义震动强度

方案B（在线版，后续迭代）：
  接入公交实时数据API（如高德/百度公交API）
  → 获取实时到站信息
  → 精确到站提醒
  → 支持换乘提醒
```

### 6.2 全局语音转文字方案

```
SpeechToTextService（前台服务）：
  → 常驻通知栏（低耗电模式）
  → Android SpeechRecognizer 连续识别
  → 识别结果通过 FusionPerceptionEngine 分发
  → 可选：悬浮窗实时显示转写文字
  → 联动TTS：重要信息自动播报
```

### 6.3 应急求助方案

```
EmergencyHelpScreen：
  → 预设6种求助场景（身体不适/迷路/交通事故/火警/走失/其他）
  → 每种场景对应预设文字模板
  → 一键触发：发送位置+模板文字到紧急联系人（短信）
  → 可选：同时发送到基地帮扶中心
  → 可选：触发最高级别震动+闪光灯（吸引路人注意）
```
