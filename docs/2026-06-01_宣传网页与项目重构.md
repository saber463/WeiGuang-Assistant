## 一、项目文件重构

### 1.1 CSS/JS分离
将 `index.html` 中的内联 `<style>` 和 `<script>` 提取为独立文件：

| 文件 | 说明 | 行数 |
|------|------|------|
| `css/style.css` | 主页面样式 | 1280行 |
| `js/main.js` | 主页面交互脚本 | 602行 |
| `index.html` | 仅HTML结构 | 347行 |

### 1.2 代码注释规范
- CSS：每个区块有 `/* ======== 区块名称 - 说明 ======== */` 格式的分区头
- JS：每个IIFE和函数都有中文注释说明用途和参数
- HTML：每个区块有 `<!-- 区块名称 -->` 格式的注释

## 二、宣传网页

### 2.1 文件结构
```
web/
├── promote.html          # 宣传页HTML
├── css/
│   └── promote.css       # 宣传页样式（暗色+暖橙光晕）
├── js/
│   └── promote.js        # 宣传页交互脚本
```

### 2.2 设计理念
- **暗色主题**：背景色 `#0D0A07`，营造"黑暗中的微光"意境
- **暖橙光晕**：主色 `#D4893C`，传递温暖与希望
- **粒子效果**：20个随机浮动的暖色光粒子，象征"微光"
- **滚动动画**：IntersectionObserver 驱动的淡入/滑入效果

### 2.3 页面结构

| 区块 | 说明 | 设计特点 |
|------|------|----------|
| **Hero首屏** | 全屏暗色背景 + 光粒子 + 手机模型 | 毛玻璃导航、渐变按钮、数据统计 |
| **我们的故事** | 左侧大数字2700万 + 右侧叙事 | 情感化设计、价值观标签 |
| **核心功能** | 12个功能卡片网格 | 悬停动画、分类标签 |
| **技术实力** | 四层架构展示 + 数据亮点 | 层级箭头、数据卡片 |
| **下载区** | CTA号召行动 + 二维码 | 大按钮、检查清单 |
| **页脚** | 品牌信息 + 链接 | 三列布局 |

### 2.4 交互效果
1. 导航栏滚动监听（毛玻璃效果）
2. 滚动显示动画（IntersectionObserver）
3. Hero区域20个光粒子浮动
4. 移动端全屏菜单
5. 功能卡片悬停动画
6. 技术卡片悬停位移
