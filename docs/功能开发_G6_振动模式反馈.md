## 一、背景与目标

**G6 振动模式反馈** 是为听障/言语障碍用户补全"多模态提醒闭环"的基础组件。

**为什么需要它**：在睡眠/静音场景中，闪光灯不可见、屏幕无感知，振动是唯一可靠的提醒通道。不同紧急程度的声音/事件需要不同的振动强度与频率，让用户仅凭触觉就能区分事件类型（火灾警报 vs 门铃 vs 电话）。

**核心关系**：G6 是后置功能 G1（声音事件分类）多模态提醒的基础组件，因此放在路线图**阶段1**先行实现，先于 G1。

**最终交付**：实现 `VibrationController` 单例（与现有 `FlashlightController` 并行对称设计），提供：
1. 多种预设振动模式（按事件类型区分强度和频率）
2. 与闪光灯控制联动的多通道提醒入口
3. 提醒设置页（`AlertSettingsScreen`）中可选的振动模式 UI

## 三、实施方案

### 3.1 新增文件

| 文件 | 职责 |
|------|------|
| `data/model/VibrationPattern.kt` | 振动模式数据定义：枚举 5 类事件（火灾/门铃/电话/婴儿哭/自定义），每类含波形参数（timings、amplitudes、repeat） |
| `core/VibrationController.kt` | 振动控制器单例：封装 Android `Vibrator`/`VibrationManager`，提供 `vibrateVibrationEffect()/vibrateLegacy()`、`vibratePattern(event)`、`testPattern()` |

### 3.2 修改文件

| 文件 | 修改内容 |
|------|---------|
| `WeiguangApplication.kt` | 在 `onCreate()` 调用 `VibrationController.init(this)` |
| `ui/screen/alert/AlertSettingsScreen.kt` | 1) "测试震动"按钮接入 `VibrationController.testPattern`；2) 新增"事件振动模式"选择区（5 类事件 + 测试） |

### 3.3 VibrationPattern 设计（核心逻辑）

采用 Android `VibrationEffect.createWaveform(long[] timings, int[] amplitudes, int repeat)` 波形模型：

| 事件 | 语义 | timings(ms) | amplitudes | 说明 |
|------|------|------------|-----------|------|
| 火灾警报 | 强连续 | [0,600,200,600,200,600] | [255,0,255,0,255,0] | 三连强振 |
| 门铃 | 双振 | [0,200,300,200] | [120,0,120,0] | 两段轻振 |
| 电话铃声 | 三短振 | [0,150,150,150,150,150] | [160,0,160,0,160,0] | 三短 |
| 婴儿哭声 | 长+短交替 | [0,500,150,300,150] | [100,0,180,0,180,0] | 由轻渐重 |
| 自定义 | 用户自定义 | [0,300,200,300] | [180,0,180,0] | 默认双振 |

### 3.4 VibrationController API

- `init(context)`：获取系统 Vibrator 服务（Android 8.0+ 用 `VibrationManager`，低版本用旧 `Vibrator`），兼容 minSdk 24
- `isVibratorAvailable()`：设备是否支持振动
- `vibratePattern(events)`：按事件类型执行对应波形
- `testPattern(pattern)`：预览某组波形（供设置页测试按钮使用）
- `cancel()`：停止当前振动

### 3.5 与 FlashlightController 联动（预留）
G1 实现时，多模态提醒 = `VibrationController.vibratePattern(event)` + `FlashlightController.blink(...)` + 弹窗通知。本版本先完成振动侧能力，联动在 G1 中编排。

## 四、验证方式

1. `gradlew.bat :app:assembleDebug` 编译通过。
2. 模拟器/真机安装：提醒设置页 → 打开震动提醒 → 点击"测试震动"有振动反馈。
3. 选择不同事件模式并点击测试，振动强度/频率符合预设。
4. 设备不支持振动时，相关按钮禁用并提示。
