## 一、背景与目标

为听障/言语障碍用户提供家庭场景的发音练习工具，面向 2780 万听障人士中缺乏家庭语训支持的人群。核心闭环：

1. **音素级发音评估**：用户跟读目标音素/词语/短句，系统比对发音准确度，定位错误并给出原因；
2. **口型/动作指导**：展示目标内容的发音动作要点（口型、舌位、气息），辅助正确构音；
3. **纠正建议**：基于中文常见易混淆音（n/l、zh/z 等）映射到具体纠正指导；
4. **训练进度管理**：Room 持久化训练记录，展示连续打卡 streak 与近 7 天得分趋势。

## 二、技术方案

### 2.1 课程体系（分级递进）

`RehabCourseCatalog`（object 内置词库）：
- 四级递进：单音素 → 音节 → 词语 → 短语（对齐 SLP 构音训练流程）；
- 覆盖声母单音素（zh/z/n/l）、对比音节（na/la）、日常/求助/情感高频短语；
- 每课含 `target`（目标文本）、`mouthDesc`（口型要点）、`breathDesc`（舌位/气息纠正要点）。

### 2.2 发音评估引擎

`PronunciationEvaluator`（纯函数，可独立测试）：
- 文本归一化（去空白、标点、统一小写）；
- 计算目标与识别文本的 **Levenshtein 编辑距离** → 归一化为 0~100 相似度评分；
- 回溯编辑路径，**定位逐字错误明细**（替换/漏读）；
- 按常见中文易混淆音映射（n/l、zh/z、ch/c、sh/s 等）生成纠正建议，评分偏低时附加课程舌位/气息要点。

> **工程化取舍说明**：在尚未引入 Vosk 音素级输出的前提下，以「识别文本 vs 目标文本」的文本相似度作为发音准确度代理指标。该指标可随技术演进替换为音素级对比，UI 与数据模型无需改动。

### 2.3 训练交互（复用现有能力）

- **发音示范**：`TtsController.speak(target)` 播放标准音；
- **跟读识别**：`VoiceRecognizer`（Android zh-CN 语音识别）实时输出 partial/final 识别文本；
- **评估落库**：评估结果写入独立 Room 库（见下），供进度统计。

### 2.4 进度管理

`RehabRepository`（独立 Room 库 `RehabDatabase`，避开主库版本）：
- `RehabRecord` 实体：date / lessonId / target / score / durationMs；
- `currentStreak()`：从今天往前统计连续打卡天数；
- `recentSeries(7)`：近 7 天每日得分序列（无记录日为 0），供柱状图绘制；
- 沿 `fallbackToDestructiveMigration` 先例。

## 四、验证

1. `gradlew.bat :app:assembleDebug` **编译通过（2026-08-21，exit code 0）**。
2. 首页点击"言语康复" → 进入训练/进度双 Tab。
3. 训练 Tab：选择课程 → "听示范" TTS 播报 → "开始跟读" 识别 → "提交评估" 展示评分与纠正建议；评估结果自动写入进度库。
4. 进度 Tab：展示 streak、近 7 天得分柱状、训练历史列表。

## 五、实施记录

- **评估指标**：编辑距离优先保证评分可工程化、可测试；错误明细定位通过 DP 回溯实现（含漏读/替换判定）。
- **资源管理**：`VoiceRecognizer` 在训练 Tab `remember` 创建，`DisposableEffect.onDispose` 释放语音与 TTS，避免泄漏。
- **音素对比优化**：内置 `n/l`、`zh/z` 等易混淆音映射，命中时给出精准舌位/气流指导，而非通用提示。
- **编译问题处理**：修正 `when` 穷尽性、补充 `mutableLongStateOf` import、`LazyColumn` 内容区不可直接调用 `Spacer`（需 `item {}` 包裹）——沿用 G7 修复经验。
