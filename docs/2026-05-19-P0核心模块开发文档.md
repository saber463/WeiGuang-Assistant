# 微光畅行 - P0核心模块开发文档

## 文档信息
- **版本**: v1.1.0
- **创建日期**: 2026-05-19
- **目标**: 实现三个P0核心无障碍功能模块
- **服务对象**: 视障且言语障碍人群

## 模块概览

### P0-1: 双向手语互通模块
**目标**: 让听障用户可以快速表达高频需求，并把内容展示给听人

**核心功能**:
1. **语音转手语** - 用户说话，系统识别后匹配手语动画展示
2. **手语转语音** - 用户做手语，系统识别后转换为文字并语音播报
3. **高频短语库** - 预置30条日常紧急用语

**技术实现**:

#### 1. SignLanguageManager - 核心管理器
- **位置**: `feature/signlanguage/SignLanguageManager.kt`
- **职责**: 
  - 管理语音识别和手语识别两种模式
  - 协调TTS语音播报
  - 维护双向通信状态
- **核心方法**:
  - `startSpeechToSignMode()` - 启动语音到手语模式
  - `startSignToSpeechMode()` - 启动手语到语音模式
  - `selectSignPhrase()` - 选择并展示手语短语
  - `speakText()` - 语音播报文字

#### 2. HandGestureRecognizer - 手势识别器
- **位置**: `feature/signlanguage/HandGestureRecognizer.kt`
- **技术**: CameraX + 简化皮肤检测算法
- **功能**:
  - 实时视频流处理
  - 手部关键点检测
  - 手势类型识别（握拳、张开手掌、挥手等）
- **依赖**: `androidx.camera:camera-core:1.3.4`

#### 3. LottieAnimationPlayer - 动画播放器
- **位置**: `feature/signlanguage/LottieAnimationPlayer.kt`
- **依赖**: `com.airbnb.android:lottie:6.1.0`
- **功能**:
  - 播放Lottie格式的手语动画
  - 支持动画循环播放
  - 兜底文本显示
- **动画资源路径**: `assets/animations/*.json`

#### 4. SignLanguageDatabase - 手语词库
- **位置**: `feature/signlanguage/SignLanguageDatabase.kt`
- **预置数据**:
  - 30条高频手语短语
  - 8个分类（日常需求、健康相关、紧急求助、礼貌用语等）
  - 关键词映射表
- **分类统计**:
  - 日常需求: 5条
  - 健康相关: 7条
  - 紧急求助: 4条
  - 礼貌用语: 7条
  - 其他: 7条

#### 5. SignLanguageMatcher - 匹配算法
- **位置**: `feature/signlanguage/SignLanguageMatcher.kt`
- **算法**:
  - 文本相似度匹配（编辑距离 + 关键词权重）
  - 手势特征匹配（基于landmark距离和手势类型）
  - 频率加权排序
- **匹配流程**:
  1. 文本规范化（去除标点、分词）
  2. 关键词提取
  3. 多级匹配（完全匹配 > 前缀匹配 > 包含匹配）
  4. 频率权重调整
  5. Top-N排序输出

**预置高频短语**:
```
紧急求助:
- 请帮帮我 (频率: 100)
- 救命 (频率: 100)
- 请联系家人 (频率: 94)
- 打120 (频率: 98)

日常需求:
- 我要去厕所 (频率: 98)
- 我要喝水 (频率: 95)
- 我饿了 (频率: 91)
- 我渴了 (频率: 90)

健康相关:
- 我不舒服 (频率: 96)
- 我要吃药 (频率: 92)
- 我头疼 (频率: 88)
```

### P0-2: 全局强提醒模块
**目标**: 对静音、低音量、易漏看通知等场景进行强化补偿

**核心功能**:
1. **通知抓取** - 实时获取系统通知
2. **音量强制控制** - 解除静音、拉满音量
3. **三重提醒联动** - 震动 + 铃声 + 灯光闪烁

**技术实现**:

#### 1. EnhancedNotificationListenerService - 通知监听服务
- **位置**: `feature/notification/EnhancedNotificationListenerService.kt`
- **继承**: `NotificationListenerService`
- **功能**:
  - 拦截指定应用的通知
  - 按关键词过滤通知
  - 记录最近50条通知
- **拦截规则**:
  - 按包名拦截（可配置）
  - 按关键词拦截（标题/内容/分类）
  - 优先级匹配
- **数据字段**:
  - 包名、应用名、标题、内容
  - 时间戳、优先级、分类
  - 震动/声音/灯光标记

#### 2. AudioManagerController - 音量控制器
- **位置**: `feature/notification/AudioManagerController.kt`
- **功能**:
  - 获取/设置各音频流音量
  - 强制拉满铃声音量
  - 解除勿扰模式
  - 请求音频焦点
- **支持音频流**:
  - `STREAM_NOTIFICATION` - 通知音量
  - `STREAM_ALARM` - 闹钟音量
  - `STREAM_RING` - 铃声音量
  - `STREAM_MUSIC` - 媒体音量
- **关键方法**:
  - `maximizeAllCriticalVolumes()` - 最大化所有关键音量
  - `disableDoNotDisturb()` - 禁用勿扰模式
  - `requestAudioFocus()` - 请求音频焦点

#### 3. TripleAlertSystem - 三重提醒系统
- **位置**: `feature/notification/TripleAlertSystem.kt`
- **提醒等级**: 低/中/高/紧急
- **震动模式**:
  - 低: 100ms开/100ms停
  - 中: 200ms开/100ms停 × 2
  - 高: 300ms开/100ms停 × 3
  - 紧急: 500ms开/100ms停 × 4
- **灯光提醒**:
  - 闪光灯闪烁
  - 屏幕全屏闪烁
  - 颜色等级区分（黄→橙→红）
- **铃声提醒**:
  - 时长: 1s/2s/3s/5s
  - 自动请求音频焦点
- **硬件能力检测**:
  - 震动马达检测
  - 闪光灯检测
  - 屏幕闪烁检测

**使用示例**:
```kotlin
val alertSystem = TripleAlertSystem(context)

// 触发最高级提醒
alertSystem.triggerTripleAlert(AlertLevel.HIGH)

// 只震动
alertSystem.setVibrationOnly(AlertLevel.MEDIUM)

// 停止所有提醒
alertSystem.stopAllAlerts()
```

### P0-3: 环境音聆听模块
**目标**: 在不依赖持续联网的前提下，实现环境声事件捕获

**核心功能**:
1. **音频实时采集** - AudioRecord持续录音
2. **人声识别** - TFLite离线模型推理
3. **后台驻留** - 前台服务 + WakeLock保活
4. **事件触发** - 检测到人声时联动提醒

**技术实现**:

#### 1. AudioCaptureManager - 音频采集器
- **位置**: `feature/soundmonitor/AudioCaptureManager.kt`
- **配置**:
  - 采样率: 16000 Hz
  - 通道: 单声道
  - 格式: PCM 16bit
  - 缓冲区: 最小缓冲×2
- **功能**:
  - WAV文件录制
  - 实时音频电平监测
  - 录音暂停/恢复
  - 录音时长统计
- **输出格式**: WAV (44字节头 + PCM数据)

#### 2. VoiceDetectionClassifier - 人声识别分类器
- **位置**: `feature/soundmonitor/VoiceDetectionClassifier.kt`
- **两种模式**:
  - **TFLite模型模式**: 使用预训练模型推理
  - **简化检测模式**: 基于特征的启发式检测
- **简化检测算法**:
  1. **RMS能量检测**: >0.01认为有声音
  2. **过零率检测**: 2-15 Hz为人声特征
  3. **频谱质心检测**: 300-3400 Hz为人声范围
  4. **综合置信度**: 加权求和
- **分类类型**:
  - HUMAN_VOICE - 人声
  - MUSIC - 音乐
  - ENVIRONMENT - 环境音
  - SILENCE - 静音
  - UNKNOWN - 未知

#### 3. SoundMonitoringService - 监听服务
- **位置**: `feature/soundmonitor/SoundMonitoringService.kt`
- **服务类型**: 前台服务 (FOREGROUND_SERVICE)
- **保活机制**:
  - PARTIAL_WAKE_LOCK - CPU保活
  - startForeground() - 前台通知
  - START_STICKY - 自动重启
- **工作流程**:
  1. 启动前台服务
  2. 获取WakeLock
  3. 开始AudioRecord采集
  4. 循环进行人声检测
  5. 触发事件回调
  6. 更新前台通知
- **事件检测**:
  - 首次人声检测
  - 持续人声检测（每10次）
  - 最小间隔3秒防抖

**启动方式**:
```kotlin
// 启动监听
SoundMonitoringService.startService(context)

// 停止监听
SoundMonitoringService.stopService(context)

// 绑定服务
val intent = Intent(context, SoundMonitoringService::class.java)
context.bindService(intent, serviceConnection, Context.BIND_AUTO_CREATE)
```

## 核心基础设施

### 1. PermissionManager - 权限管理
- **位置**: `core/permission/PermissionManager.kt`
- **权限清单**:
  - `RECORD_AUDIO` - 麦克风（环境音聆听）
  - `CAMERA` - 相机（手语识别）
  - `POST_NOTIFICATIONS` - 通知（Android 13+）
  - `FOREGROUND_SERVICE` - 前台服务
  - `SYSTEM_ALERT_WINDOW` - 悬浮窗
- **权限检测**:
  - NotificationListener权限需跳转设置页面
  - 悬浮窗权限需跳转设置页面
  - 其他使用标准权限申请

### 2. HardwareDetector - 硬件检测
- **位置**: `core/hardware/HardwareDetector.kt`
- **检测能力**:
  - 震动马达（有无 + 强度控制）
  - 线性马达检测
  - 闪光灯检测
  - 通知LED检测
  - 屏幕闪烁检测
- **品牌适配**:
  - 华为: HiTouch增强提醒
  - 小米: MIUI通知增强
  - OPPO: ColorOS通知增强
  - vivo: FuntouchOS通知增强
- **自适应策略**:
  - 无震动 → 使用屏幕闪烁
  - 无灯光 → 使用震动和通知
  - 降级模式自动切换

### 数据流

#### 手语互通数据流
```
用户说话
   ↓
SpeechRecognizer 语音识别
   ↓
SignLanguageManager 处理结果
   ↓
SignLanguageMatcher 匹配手语
   ↓
显示手语动画 + TTS播报
```

#### 强提醒数据流
```
通知到达 (系统)
   ↓
NotificationListenerService 拦截
   ↓
关键词/规则匹配
   ↓
触发 TripleAlertSystem
   ↓
震动 + 铃声 + 灯光 三重提醒
```

#### 环境音监听数据流
```
前台服务启动
   ↓
AudioRecord 持续采集
   ↓
VoiceDetectionClassifier 人声检测
   ↓
SoundEventDetector 事件检测
   ↓
触发提醒（可选）
```

## 已知限制

1. **MediaPipe Hands**: 当前使用简化皮肤检测替代，正式版需接入MediaPipe
2. **TFLite模型**: 当前使用启发式算法，正式版需训练真实人声模型
3. **Lottie动画**: 需要专业团队制作30+条手语动画
4. **NotificationListener**: 部分用户可能未授权
5. **WakeLock**: 长时间后台可能影响电池续航
