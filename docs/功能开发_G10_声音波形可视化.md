# 功能开发：G10 声音波形可视化

> 版本：v1.0 | 开发日期：2026-08-21 | 时区：UTC+8 北京时间
> 对应待开发文档：`docs/微光守护_待开发文档.md` §4.4（暂缓方向，标注"可作为 G1 附加功能"）
> 状态：已完成

---

## 一、背景与目标

作为 G1 环境音监控的附加可视化能力落地：让听障用户**"看得见"周围声音的强弱**。
实时采集麦克风音频，把每帧能量绘制成随时间推进的波形竖条，并展示当前分贝声级（-60~0 dB）。
属于锦上添花的可视化项，不改动 G1 的声音匹配 / 提醒逻辑。

## 二、技术方案

### 2.1 波形分析器

`SoundWaveformAnalyzer`（实例类，独立于 `AmbientSoundMonitor`）：
- 采集参数与 `AmbientSoundMonitor` 口径一致：16kHz、单声道、PCM 16bit、2048 样本/帧（≈128ms）；
- 每帧计算 **RMS 幅度（0~1）**，推入固定长度滑动缓冲（64 条 ≈8 秒轨迹）；
- 分贝换算：`20·log10(幅值)`，限幅 -60~0 dB（`0.001f` ≈ -60dB 静音下限）；
- `levels`（波形缓冲）与 `dbLevel`（分贝）通过 StateFlow 对外发布，Compose 收集即实时刷新；
- 权限缺失 / AudioRecord 初始化失败时优雅降级，不崩溃；
- 在单线程 executor 读取，不占用主线程。

### 2.2 可视化界面

`SoundWaveScreen`（Compose）：
- **声级卡**：顶部展示当前 dB 大字；
- **波形画布**：Canvas 在深色背景上逐条绘制 RMS 缓冲，条高与幅度正比、颜色随幅度递变（低→高：青→蓝→亮蓝），最新值在最右侧，形成自右向左推进的实时反馈；
- **交互**：按钮切换"开始 / 停止"；未授权录音时给出引导且不启动；
- **生命周期**：进入页面 `remember` 创建分析器，`DisposableEffect.onDispose` 释放（停止采集 + 关闭线程池），避免麦克风/线程泄漏。

## 四、验证

1. `gradlew.bat :app:assembleDebug` **编译通过（2026-08-21，exit code 0）**。
2. 首页点击"声音波形" → 进入可视化页。
3. 点击"开始可视化"，对着麦克风说话或制造声音，波形竖条随声音强弱起伏，声级卡实时显示 dB。
4. 点击"停止"或退出页面，采集停止并释放资源。

## 五、实施记录

- **采集口径复用**：沿用 `AmbientSoundMonitor` 的采样率/通道/位深，避免引入不一致的音频处理参数。
- **可视化实时性**：帧级 RMS + StateFlow 收集，128ms 粒度对"声音强弱可视化"已足够平滑，未引入 FFT 频谱以控制复杂度。
- **生命周期**：`DisposableEffect` 释放保证离开页面不残留麦克风占用。
- **编译问题处理**：补充 `Brush`/`clip` import、颜色取色改为顶层函数（避免对 `Brush` 的无谓扩展）。

> **说明**：G10 在待开发文档中列为"暂缓"，因借鉴价值低-中。本次作为 G1 附加项实现，为已饱和的核心路线图补充轻量可视化，不阻塞后续主线。
