## 一、技术卡片图标修复

### 问题描述
"振动引擎 + AlertSystem" 技术卡片的图标显示为空白/消失。

### 根本原因
使用了不存在的 Bootstrap Icons 类名 `bi-vibrate`。Bootstrap Icons 1.11.3 中没有 `vibrate` 这个图标，正确的类名是 `bi-phone-vibrate`。

### 修复内容
| 位置 | 修改前 | 修改后 |
|------|--------|--------|
| HTML 技术卡片（第770行） | `bi bi-vibrate` | `bi bi-phone-vibrate` |
| JS techData 弹窗数据（第1108行） | `bi bi-vibrate` | `bi bi-phone-vibrate` |

## 二、吉祥物互动聊天功能

### 功能概述
在页面右下角添加可交互的吉祥物"小微"，用户点击后可打开聊天窗口，通过按钮选择了解项目信息。

### 功能特性
1. **浮动动画**：吉祥物持续上下浮动，吸引用户注意
2. **光晕效果**：底部渐变光晕 + 脉冲动画
3. **消息徽章**：页面加载3秒后显示红色数字徽章，提示有新消息
4. **聊天窗口**：点击吉祥物打开/关闭聊天窗口
5. **智能对话**：预设6个话题的问答知识库
6. **打字动画**：回复前显示"正在输入"三点跳动动画
7. **按钮导航**：底部操作按钮支持话题切换
8. **响应式适配**：移动端自适应宽度和位置

### 交互流程
```
用户点击吉祥物
    ↓
显示聊天窗口 + 欢迎消息
    ↓
用户点击底部按钮（如"核心功能"）
    ↓
显示用户消息 → 打字动画 → 显示回复
    ↓
渲染新的操作按钮 → 循环交互
```

### 知识库话题
| 话题 | 内容 |
|------|------|
| `welcome` | 欢迎语 + 4个初始按钮 |
| `about` | 项目介绍 |
| `features` | 12大功能卡片网格（含查看原理按钮） |
| `tech` | 技术栈介绍 |
| `download` | 下载指引 |
| `thanks` | 感谢语 |

### 功能卡片网格（新增）
点击"核心功能"后，聊天窗口内渲染12个功能卡片：
```
┌──────────┬──────────┐
│ 🆘 一键应急│ 🚌 公交报站│
│ [查看原理] │ [查看原理] │
├──────────┼──────────┤
│ 💊 药品识别│ 🤟 手语沟通│
│ [查看原理] │ [查看原理] │
├──────────┼──────────┤
│ ...共12个卡片...      │
└──────────┴──────────┘
```

### 功能原理弹窗（新增）
点击任意"查看原理"按钮，弹出详情弹窗：
- 显示功能emoji、名称、技术标签
- 详细的技术原理说明（HTML富文本）
- 支持点击遮罩层或✕按钮关闭
- 支持ESC键盘关闭

### 修改文件
- `web/index.html`：
  - CSS：新增 `.mascot-wrapper`、`.mascot-body`、`.mascot-chat`、`.chat-feature-grid`、`.feat-modal-overlay` 等约350行样式

## 四、吉祥物位置修复

### 问题描述
吉祥物被返回顶部按钮遮挡，无法正常显示和点击。

### 根本原因
返回顶部按钮和吉祥物都在 `position: fixed; bottom: 30px; right: 30px; z-index: 999`，完全重叠。当页面滚动后，返回顶部按钮变为可见，遮挡了吉祥物。

### 修复方案
| 元素 | 修改前 | 修改后 |
|------|--------|--------|
| 吉祥物 `.mascot-wrapper` | `bottom: 30px` | `bottom: 100px` |
| 聊天窗口 `.mascot-chat` | `bottom: 120px` | `bottom: 200px` |
| 移动端吉祥物 | `bottom: 20px` | `bottom: 80px` |
| 移动端聊天窗口 | `bottom: 100px` | `bottom: 160px` |

### 最终布局（从下往上）
```
bottom: 30px  → 返回顶部按钮
bottom: 100px → 吉祥物头像
bottom: 200px → 聊天窗口
```
