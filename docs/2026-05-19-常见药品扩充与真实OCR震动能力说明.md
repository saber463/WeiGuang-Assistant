## 4. 震动马达能力检测与调节

### 4.1 本轮新增内容

提醒页新增：

- 设备震动能力检测
- 自定义震动测试面板
- 自定义脉冲时长调节
- 自定义间隔调节
- 自定义重复次数调节
- 自定义强度调节
- 停止震动按钮

### 4.2 当前可以做到什么

通过 Android 标准振动 API，当前可以做到：

- 检测设备是否存在振动马达
- 检测设备是否支持振幅控制
- 使用波形组合实现不同节奏提醒
- 通过时长和间隔变化模拟不同“频率体感”

### 4.3 当前做不到什么

必须明确：

- Android 标准 API 不提供直接修改手机振动马达物理频率的能力
- 不同品牌手机对线性马达和高级震动特性的开放程度不同
- 本应用当前只能调节 `波形节奏`、`持续时间`、`振幅`

所以本轮“尝试更改马达在本应用的震动频率”的真实落地方式是：

- 不直接修改硬件频率
- 通过更密或更疏的波形间隔来模拟不同提醒频率体感

## 5. 验收方式

### 5.1 数据层

本轮已经执行：

```bash
python tools/build_seed_db.py
```

生成新的：

- `app/src/main/assets/db/drugs.db`

### 5.2 真机建议验证步骤

建议按下面顺序验证：

1. 打开药品页
2. 先点常见药品快捷入口，确认新增药品可检索
3. 申请相机权限
4. 打开后置相机
5. 对准药盒正面
6. 观察是否出现 OCR 原文和查询关键词
7. 点击 `使用实时识别结果查询`
8. 打开提醒页
9. 先测试预设模式
10. 再调节自定义震动参数，确认节奏变化是否可感知
