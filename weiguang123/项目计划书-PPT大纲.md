## 第5页：创意亮点① — 双屏面对面交互

**创意核心**：不是翻译软件，而是沟通终端

**交互示意**：
- 左侧屏（听障人士）：看3D数字人打手语 + 对摄像头比手语
- 右侧屏（工作人员）：看实时翻译字幕 + 正常说话
- 两人面对面，各自看各自的屏，如同自然对话

**设计理念**：不让听障人士低头看手机打字，而是抬头面对面对话

**视觉建议**：左右分屏交互示意图，中台AI引擎连接

## 第6页：创意亮点② — 场景自适应翻译

**问题**：同一句话在不同场景下，手语表达不同

**方案**：内置场景感知翻译层

**示例**：
- 输入：我要办卡
- 银行场景 → 手语：银行卡 + 办理
- 医院场景 → 手语：就诊卡 + 办理
- 政务场景 → 手语：社保卡 + 办理

**视觉建议**：树状分支图，一句话分散到四个场景

---

## 第7页：创意亮点③ — 手语热词本（千人千面）

**问题**：每个听障人士的手语习惯略有差异（类似方言）

**方案**：首创个人手语校准机制

**流程**：
1. 首次使用 → 展示20个基础词汇标准手语
2. 用户比划 → 摄像头捕捉个人版本
3. AI学习 → 建立个人手语适配模型
4. 越用越准 → 让AI适应人，而非人适应AI

**视觉建议**：四步流程图，强调循环优化

## 第8页：创意亮点④ — 情绪感知与温情交互

**洞察**：手语不仅是动作，还有表情和情绪

**方案**：MediaPipe Face Mesh 468关键点 → 实时情绪识别

**温情细节**：
- 识别焦虑/困惑 → 数字人同步柔和表情，放慢手语速度
- 识别开心/满意 → 数字人微笑回应
- 沉默超10秒 → 数字人主动问：您需要更多时间吗？

**设计理念**：技术是冷的，但交互可以是暖的

**视觉建议**：左右对比——机械翻译 vs 温情交互

## 第10页：技术架构（一页看懂）

**三层架构**：

【前端交互层】Web端 / 移动App / 小程序 / 自助终端
        ↓
【AI核心层】手语识别(ST-GCN) + 数字人合成(Diffusion+SMPL-X) + ASR/TTS(讯飞) + 对话(大模型+RAG)
        ↓
【基础设施层】云+端混合部署，边缘端ONNX量化，关键点传输仅2KB/s

**关键数据**：识别延迟 < 500ms | 带宽 2KB/s | 原型硬件 < 3000元

**视觉建议**：三层架构框图，底部关键指标

1. **配色**：蓝色主色调（科技感+信任感），辅助暖橙色（温情），白色背景为主
2. **字体**：标题粗体无衬线（思源黑体 Bold），正文常规（微软雅黑）
3. **图表工具**：架构图用 draw.io / Figma，手语示意可用简笔画
4. **动画**：简单渐入即可，不要过度特效
5. **数据来源标注**：所有数据注明出处（中国残联、国家统计局）
6. **时长控制**：15页 × 30-40秒/页 ≈ 8-10分钟，留2分钟答辩
